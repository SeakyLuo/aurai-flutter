# Aurai

Aurai，又叫阿睿，是一个手机端 Agent。用自然语言告诉它你想做什么，它会观察屏幕、调用工具、操作应用，并在完成后总结结果。

基于 Flutter 开发，目前主要支持 Android。

## 功能

- 对话与图片输入
- 操作手机应用、查看设备状态、排查网络问题
- 等待指定应用的文字或页面变化
- 需要手动操作时暂停任务，确认完成后继续
- 可选 Shizuku 高权限命令与本地 VPN 连接记录
- 查看任务进度，随时停止执行
- 读取授权文件夹中的文本和 PDF，搜索文件、保存文本结果并引用来源，通过系统面板分享文件
- 本地保存会话和执行记录
- 自定义模型服务，支持夜间模式

## 使用

安装后，在「设置 → 模型设置」中配置模型服务和 API Key，即可开始对话。需要操作手机时，按提示开启无障碍权限。

在「设置 → 设备能力」中可以接入 Shizuku 和开启本地 VPN。它们是 AI 工具，技能也可按需使用。Shizuku 需要先安装、启动并授权；本地 VPN 会替换现有 VPN，默认记录 5 分钟，只记录连接元数据，不解密 HTTPS。
