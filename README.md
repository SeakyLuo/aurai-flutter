# Aurai

Aurai 是一个手机端 Agent。用自然语言告诉它你想做什么，它会观察屏幕、调用工具、操作应用，并在完成后总结结果。

基于 Flutter 开发，目前主要支持 Android。

## 功能

- 对话与图片输入
- 操作手机应用、查看设备状态、排查网络问题
- 查看任务进度，随时停止执行
- 本地保存会话和执行记录
- 自定义模型服务，支持夜间模式

## 使用

安装后，在「设置 → 模型设置」中配置模型服务和 API Key，即可开始对话。需要操作手机时，按提示开启无障碍权限。
