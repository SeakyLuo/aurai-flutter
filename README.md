# Aurai

Aurai，又叫阿睿，是一个手机端 Agent。用自然语言告诉它你想做什么，它会观察屏幕、调用工具、操作应用，并在完成后总结结果。

也可以跟AI发起群聊。

基于 Flutter 开发，目前主要支持 Android。

## 功能

- 对话与图片输入
- 操作手机应用、查看设备状态、排查网络问题
- 等待指定应用的文字或页面变化
- 需要手动操作时暂停任务，确认完成后继续
- 可选 Shizuku 高权限命令与本地 VPN 连接记录
- 查看任务进度，随时停止执行
- 读取授权文件夹中的文本和 PDF，搜索文件、保存文本结果并引用来源，通过系统面板分享文件
- 本地保存会话和执行记录
- 自定义模型服务，支持夜间模式

## 使用

安装后，在「我 → 模型供应商」中配置模型服务和 API Key，再在「我 → 设置 → 模型设置」中选择默认模型，即可开始对话。需要操作手机时，按提示开启无障碍权限。

在「设置 → 设备能力」中可以接入 Shizuku 和开启本地 VPN。它们是 AI 工具，技能也可按需使用。Shizuku 需要先安装、启动并授权；本地 VPN 会替换现有 VPN，默认记录 5 分钟，只记录连接元数据，不解密 HTTPS。

「发现」包含小程序库、技能库和工具库。小程序库展示发布人，点开详情后即可运行；内置 TipOff 无需手动导入 HTML。库中只展示内置和手动发布的版本；未发布作品留在「我的」。这是本机内容库，未连接在线市场。

在「我的」打开自己创建的小程序，可以填写名称和简介并发布。修改草稿不会改变库中的已发布代码；需要再次发布更新。发布人使用当前个人资料，创建者另行保留。添加的小程序保留原发布人，不能直接作为自己的作品发布。

从库中「添加并打开」会创建独立副本，不复制作者的聊天或存档。更新仅替换代码；撤下只隐藏库条目，已添加版本和存档保留。数据库版本 39 新增发布记录和添加记录两张表，已有作品默认不发布，旧 TipOff 沿用原存档目录。

TipOff 的代码随 App 打包，存档独立保存在本机。更新内置版本前，在 TipOff 项目执行 `npm run build:aurai`，再在本项目执行：

```bash
python3 scripts/sync_tipoff.py /完整路径/dist-aurai/tipoff.html
flutter build apk --debug
```

重新构建 App 后，进入「发现 → 小程序库 → TipOff → 打开」。替换内置代码保留既有存档；此入口需要 Android。新增原生 AI 桥接后需要完整重启构建，不能只热重载。
