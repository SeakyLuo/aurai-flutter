# 安宁列车 TRPG 车厢

本文件列出八节车厢的环境、设施、常见动物和故障变化。角色创建与行动规则见[主设定](./安宁列车TRPG设定.md)。

每节车厢都是一张可自由选路的方格地图，两端连接前后车厢。尺寸按实际布局确定，`8 × 20` 只是早期草案。车厢内有通道、墙、设施和难走地形；环境标签标在实际格子上，故障可以改变标签：湿地会结冰，沙漠也可能漏水。

下表只列出各车厢**常见的动物物种**。首轮可选玩家动物见主设定中的六种；其他物种先作为世界中的乘客，补好动物技能后再开放给玩家选择。它们都不与车厢绑定。具体乘客的名字、行为、线索和立场由剧本或主持人安排。

| 车厢 | 环境与设施 | 常见动物 | 故障带来的变化 |
| --- | --- | --- | --- |
| 冻原 | 冰雪、强风；保温管、防风门 | 企鹅、北极狐、雪鸮 | 保温管漏水后出现积水或薄冰；防风门卡住。 |
| 沙漠 | 沙地、强光；遮阳层、储水点 | 骆驼、耳廓狐、沙蜥 | 冷却停摆后变成高温区；水管破裂后局部出现浅水。 |
| 热带雨林 | 藤蔓、高处、人工降雨；灌溉阀、藤蔓桥 | 变色龙、树懒、鹦鹉 | 降雨失控形成积水；停电后出现黑暗。 |
| 湿地 | 浅水、泥地；水泵、架高步道 | 河马、河狸、鹈鹕 | 水位上涨淹没通道；异常冷气让局部水面结冰。 |
| 温带草原 | 开阔、微风；观测台、广播柱 | 猎豹、野猫、土拨鼠 | 烟尘遮挡远处视线；广播柱误报。 |
| 洞穴 | 黑暗、潮湿岩壁；照明、通风机 | 蝙蝠、仓鼠、穿山甲 | 岩壁坍塌产生缝隙；漏水或停风改变路线。 |
| 水下舱 | 水流、积水；观察窗、供氧阀 | 章鱼、海龟、小丑鱼 | 水流倒转、舱门封闭；漏电区域不能直接下水。 |
| 火山地带 | 热气、蒸汽；隔热层、排气阀 | 乌鸦、温泉蝇、山羊 | 蒸汽喷口乱开；冷却失效，也可能局部结冰。 |

车厢的环境会影响行动，但不会给同名动物额外加成。玩家选仓鼠也可以从沙漠上车；火山地带出现什么线索，则要看当局事故的剧本。
