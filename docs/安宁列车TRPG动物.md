# 安宁列车 TRPG 动物

首轮开放六种玩家动物。每名角色选一种动物，获得对应的一个动物技能；还会另选一种职业。动物技能体现物种自带的通用本领，不绑定职业或起始车厢。角色创建和掷骰规则见[主设定](./安宁列车TRPG设定.md)。

技能只写效果。具体怎么用、现场是否说得通，由玩家描述，DM 裁定。

| 动物 | 技能 | 效果 |
| --- | --- | --- |
| 仓鼠 | 颊囊 | 可以额外携带 1 件空间为1的道具。 |
| 章鱼 | 八手并用 | 一次行动可使用的道具数量无上限。 |
| 鹦鹉 | 学舌 | 学会同车厢队友使用过的职业技能。 |
| 山羊 | 什么都敢吃 | 吃掉 1 件道具，将一次 D6 视为自然 6。 |
| 猎豹 | 疾奔 | 放弃本轮行动，移动最多 10 格。 |
| 野猫 | 九条命 | 掷出自然 1 可重掷一次，接受新结果。 |

## 后续可选动物

[车厢文档](./安宁列车TRPG车厢.md)中的企鹅、骆驼、河马、河狸、变色龙、蝙蝠、乌鸦，以及北极狐、雪鸮、耳廓狐、沙蜥、树懒、鹈鹕、土拨鼠、穿山甲、海龟、小丑鱼和温泉蝇，都可以在后续成为玩家动物。开放一种前，先为它写好能改变玩家选择或行动结果的动物技能；环境型技能按现场的冰、沙等条件触发，不绑定在某节车厢。
