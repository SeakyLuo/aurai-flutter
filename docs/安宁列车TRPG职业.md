# 安宁列车 TRPG 职业

本文件列出首轮可选的六种职业。每名玩家在[主设定](./安宁列车TRPG设定.md)中选一种动物，再从这里选一种职业。职业与动物、起始车厢不绑定。

普通的做饭、采购、维修和使用道具谁都能尝试。职业技能明确改变产出、成本、资源消耗或判定结果。技能可以反复使用，不设置每局使用次数；具体物资与现场条件仍按实际记录结算。

| 职业 | 技能 | 效果 |
| --- | --- | --- |
| 厨师 | 精打细算 | 同样食材，制作同一种餐食的出餐量 ×1.25。 |
| 商人 | 进货渠道 | 外部采购价格 ×0.9。 |
| 机械师 | 节省耗材 | 维修材料消耗 ×0.75。 |
| 园艺师 | 栽培 | 留出种植空间并投入 1 份种子，经过一站后收获 3 份对应食材；只能种适合现有环境的品种。 |
| 服务员 | 端稳 | 使用有次数限制的道具时，有 50% 概率不扣使用次数，效果正常结算。 |
| 桌游 DM | 改剧本 | 队友掷骰失败时，可以放弃自己下一次行动，将这次结果改为 3。 |

## 结算说明

- **厨师**：按实际负责制作的一批同款餐食计算，完整份数向下取整，例如原本能做 4 份，技能后做 5 份。额外产出是正常的一人份餐食，保留该批餐食的配料与饮食要求；原本四份鱼饭可以出五份鱼饭，但素饭不会变成鱼饭。已经完成的餐食不通过再次处理反复乘倍率。
- **商人**：对已谈妥的外部采购总价乘 0.9，金额保留两位小数。例如原价 20 元，实际付 18 元；只改变价格，不改变商品、库存或所有权。团队内部调拨、卖给乘客的报价与退款不使用此倍率。
- **机械师**：先明确正常维修要消耗哪些材料，各项实际消耗乘 0.75，材料按份记录剩余量。例如需要 4 份封堵材料时消耗 3 份，需要 1 份时消耗 0.75 份。整件管箍、供暖组件等不可分割零件仍需完整安装，工具不因技能复制；无耗材的维修直接按原做法完成。
- **园艺师**：种植时扣除种子，并记下品种与实际种植位置。列车到达下一站且生长条件保持可用后，收获一次、加入共享库存并清除本次种植记录。这里是轻量游戏的生长规则，不计算分钟；持续收获需再次投入种子与实际空间。雨林等车厢的可用种植区可以利用，但不能占通道或靠一句描述无限增加种植位置。
- **服务员**：正常完成一次道具使用后，程序进行一次 50% 判定，成功则免去该次使用原本应扣的次数；失败照常扣除。不限次数的道具不需要判定。猴子一次使用两件道具时分别判定；同一次道具使用只触发一次端稳。食材、种子、维修材料与采购支出不属于道具次数，不能使用此技能免除。
- **桌游 DM**：放弃下一次行动是确定的代价，不能在该次行动之前反复承诺放弃同一次行动。结果改为 3，按有代价的进展处理；移动骰与搜索道具的概率不使用此技能。
