# 安宁列车 TRPG 职业

本文件列出首轮可选的六种职业。每名玩家在[主设定](./安宁列车TRPG设定.md)中选一种动物，再从这里选一种职业。职业与动物、起始车厢不绑定。

普通的拍照、修理或询问谁都能尝试。技能能反复使用；具体做法由玩家提出、DM 裁定。

| 职业 | 技能 | 效果 |
| --- | --- | --- |
| 桌游 DM | 改剧本 | 队友掷骰失败时，可以放弃自己下一次行动，将这次结果改为 3。 |
| 摄影师 | 现场取证 | 拍摄现场时，DM 指出照片中一处容易忽略的真实细节；照片还可用于之后比对现场变化。 |
| 萨满 | 问物 | 可以询问一件物品亲历过的事。 |
| 软件工程师 | 自动化 | 成功操作一处设施后，可让它持续重复同一操作；写入新流程、断电或设施失灵时，旧流程停止。 |
| 列车员 | 调度 | 花一次行动，指挥至多 2 名愿意配合的乘客各移动 4 格，并各做一次行动。 |
| 机械师 | 应急检修 | 接触故障机器并花一次行动排除眼前的卡滞；此后每轮用自己的行动维持，机器就能临时运转，离开后故障复现。 |
