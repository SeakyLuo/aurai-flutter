# 安宁列车：小游戏设计思路

> 讨论稿。先确定玩家在一局里反复做什么、为什么愿意再玩；回合数、时长和数值等试玩后再定。此前的 TRPG 文档保留为动物、职业、道具和车厢的素材，不直接视作小游戏规则。

## 一句话

六名玩家扮演列车上的动物乘客，一起处理接连发生的荒唐事故，让列车安全抵站。每个人还带着一件想在旅途中完成的荒唐小目标。大家都想帮忙，也都想在车厢广播里留下自己的英雄事迹。

## 一局的两层目标

- **共同目标**：列车遇到公开的事故，玩家分头调查、开路、救援和修复。事故会影响车厢地图与之后的行动；全队共同承担抵站结果。
- **个人小目标**：每人开局从两张目标卡里选一张。目标通过正常帮助列车时的行动完成，不要求额外找专属钥匙，也不鼓励故意损害共同目标。全队完成旅程后，按小目标给角色颁发搞笑称号；个人目标不替代共同胜负。

小目标以**行为**为条件，不绑定动物或职业。例如“全车都认识我”要求在不同车厢参与处理事故，“列车指定快递员”要求把道具交给队友且被用于事故，“道具体验官”要求用不同道具帮忙。猎豹可能更容易赶路，仓鼠可能更适合带东西，但任何动物都可以尝试这些目标。以后若写限定目标，应让它适用于一组拥有相近本领的动物，而不是为单一物种写专属任务。

## 反复进行的玩法

1. **看到问题**：地图和事故卡直接展示哪里出事、接下来可能怎样变化。必需信息应有固定获得方式。
2. **商量分工**：六人决定谁去现场、谁带道具、谁开路或护送乘客。可以各走各的，也可以会合交换道具。
3. **在车厢行动**：沿用目前讨论过的基础——每回合掷 D6 作为移动上限，可提前停下；移动之外做一次有结果的行动。地形、障碍和道具影响路线与做法。
4. **事故推进**：六人行动后按事故卡更新地图和乘客处境。玩家做过的修复、搭出的路与用掉的道具继续保留。
5. **抵站回顾**：看列车和乘客的结果，再揭晓各自的小目标与称号。

公共事故不能只是一处“到场按一下就修好”的点。每张事故卡至少要写清**现场变化、玩家需要作出的选择、几种合理处理途径，以及处理后的持续影响**。道具和技能提供新办法或更好的结果；不作为唯一的通关钥匙。主持人可负责叙述和裁定玩家提出的剧本外办法，卡片本身要足以结算常规玩法。

## 一趟列车如何变化

一局会经过多节相连的车厢，公开事故分阶段出现；上一阶段留下的通路、损坏、道具和乘客位置进入下一阶段。玩家在旅途中可能获得新道具，并因背包只有 3 格而决定留下、使用或转交什么。动物、职业、道具和车厢分别设计，可以自由组合。

重玩主要靠**不同的事故组合、车厢布局、起始道具与个人目标**。事故组合要预先检查因果与通关可能性，避免把无关事件随机拼成一局。已经知道某次事故答案的玩家，再玩时仍应面对不同的路线、时机和队友分工。

## 首个试玩版本要验证什么

先做一趟规模有限但完整的旅程：几节车厢、一组会持续改变地图的事故、足够六人选择的通路与行动、以及一小叠通用个人目标卡。用现有动物和道具表筛选出真正会影响移动、行动或协作的效果。试玩重点记录：六个人是否持续有事可做；有没有人只是在等轮到自己；个人目标是否制造笑点而不妨碍合作；同一事故换布局和道具后是否还想再玩。

**两小时是体验目标，不是把地图放大或增加修理点就能保证的时长。**第一次试玩后再决定一局需要多少阶段、个人目标和事故卡。
