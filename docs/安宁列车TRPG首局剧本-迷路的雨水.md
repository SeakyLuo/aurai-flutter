# 安宁列车首局：迷路的雨水

这是一局供 **6 名玩家＋1 名主持人**玩的完整剧本，目标时长 **2—3 小时**。使用[主设定](./安宁列车TRPG设定.md)的移动、行动、判定和背包规则。主持人先读完本文，玩家只听开场说明。四节车厢始终在同一张连续地图上，玩家可以分头走、会合、交换道具；两段事故之间不传送角色，也不重置背包。

## 这一局在做什么

列车的水循环同时出了两处故障：雨林回水滤网堵住，洞穴中的回水管裂开。湿地因此涨水，雨林越来越干，末端的火山车厢也失去冷却。玩家要救出湿地的三名乘客、修好两处故障，随后进入火山车厢处理余热并带出两名乘客。水循环恢复只是**前半局的成果**，不会直接结束游戏。

结局由四个目标决定，顺序由玩家选：

1. 从湿地带出 3 名乘客。
2. 补好洞穴中的裂管。
3. 清掉雨林回水滤网里的堵布。
4. 火山车厢降温，并带出里面的 2 名乘客。

**完整胜利**：水循环在第 24 轮末的紧急停车前恢复，五名乘客都到达指定安全区，火山车厢在其热量到顶前降温。否则列车停车，仍可继续救人，最后按完成了哪些目标讲述结局。没有隐藏的第五个按钮。

## 开场时告诉玩家

“你们在洞穴车厢。通向湿地的一端传来呼救，通向雨林的一端已经很久没下雨。洞穴右侧的回水管一边喷水，一边发出像有人在吹口哨的声音。列车员说，火山车厢的冷却水也快用完了，但隔热门暂时还关着。车厢之间的门正常开放，想先去哪边由你们决定。”

把六名玩家放在洞穴 `D13—I13`，每人一格。开局按[道具表](./安宁列车TRPG道具.md)的全局数量，随机每人送一件：**安全绳网、封堵泡沫、多用工具钳、头灯、便携喇叭、移动 BGM 机**。这些道具占背包空间，使用次数照表。

## 地图通则

每节车厢 **12 列（A—L）× 28 行（01—28）**，外边界是墙。玩家横竖移动，普通地面进入消耗 1 点，难走地面消耗 2 点；没列出的内部格是普通地面。乘客跟着引路玩家走，不另掷移动骰，也不占玩家的格子。玩家每轮仍掷移动骰，即使正在领人。

从列车前端到后端依次是 **热带雨林—洞穴—湿地—火山地带**。相邻车厢通过中间两格的门连接，跨门进入下一格消耗 1 点：

| 相邻车厢 | 连接的门 |
| --- | --- |
| 雨林 ↔ 洞穴 | 雨林 `F28—G28` ↔ 洞穴 `F01—G01` |
| 洞穴 ↔ 湿地 | 洞穴 `F28—G28` ↔ 湿地 `F01—G01` |
| 湿地 ↔ 火山 | 湿地 `F28—G28` ↔ 火山 `F01—G01` |

玩家可把纸分给三组，同时记录各自的位置。进出车厢不需要全员到齐。某个玩家修好设施，立即更新所有人的地图状态。

## 第一段：水到底去哪了

三件事同时发生：洞穴漏水、雨林堵塞、湿地有人受困。玩家不必先拿线索才能修理；到达设施后可以直接操作。所有必需线索**检查就能拿到**，不掷调查骰。

### 洞穴：裂开的回水管

| 坐标 | 内容与效果 |
| --- | --- |
| `D09—E20`、`H09—I20` | 碎石地，进入消耗 2 点移动。中间 `F—G` 两列是较快的走道。 |
| `J18` | 裂开的回水管，周围 `H16—K20` 是浅水，进入消耗 2 点。先到这里的玩家直接看见裂口。 |
| `K06` | 工具柜里有 **1 个管箍**。顺手拿起即可，背包占 1 格；装到 `J18` 花 2 次行动，可以由两名玩家先后完成。装好后裂管永久修复。 |
| `B12` | 泄压手轮。花 1 次行动，让 `J18` 停止喷水 **3 轮**；时间到会重新喷，除非裂管已修好。该手轮可再次使用。泄压时洞穴 `B15—E20` 变成浅水，手轮失效后恢复。 |
| `D07` | 维护记录：“昨天在雨林滤网上拦住一块布，别忘记拿走；洞穴这段回水管有裂纹，管箍在工具柜。”读记录花 1 次行动。 |

管箍是本局固定场景道具，仅此 1 个，用完移除。**封堵泡沫**可按道具效果临时堵住 `J18`，其 2 轮结束后仍需正式修复。玩家也能提出别的修管办法，由主持人按行动骰处理；管箍是无需临场裁定的保证解法。

### 热带雨林：没有雨的雨林

| 坐标 | 内容与效果 |
| --- | --- |
| `B09—E18` | 密藤区，进入消耗 2 点移动。 |
| `F14—G14` | 干倒的树干占住两格，不能走。花 1 次行动搬开，此后可通行；也可绕路。 |
| `B12` | 快见底的雨水箱。花 1 次行动检查，得知：“湿地送来的水没有到这里。” |
| `J20` | 管路示意牌。花 1 次行动查看，得知滤网检修口在 `C04`、回水管经过洞穴。 |
| `C04` | 回水滤网检修口。花 1 次行动开盖；再花 1 次行动用**多用工具钳**取出堵布，或不用工具花 2 次行动取出。打开后能直接看到堵布和写着“记得取走”的纸条。 |

拿掉堵布后，雨林开始恢复降雨。如果洞穴裂管还没修好，恢复的水会从裂口喷出：从下一轮起，洞穴 `H10—K24` 变成浅水，直到裂管修好。若先修裂管，再取堵布，就不会出现这次扩大漏水。**两种顺序都能通关**，只是之后的路线不同。

### 湿地：三名乘客在水中央

| 坐标 | 内容与效果 |
| --- | --- |
| `D10—I22` | 深水池，不能直接步行穿过。`F10—F18`、`F18—H18` 是可走的架高步道；`H18—I19` 的四格是高出水面的小岛。 |
| `H18—I19` | 河马、鹈鹕、河狸三名乘客。玩家走到其中一名的相邻格，花 1 次行动让其跟随。一名玩家同时只能领一名；乘客愿意配合，不需要说服检定。 |
| `B21` | 水泵还在转，回水量却不足。检查花 1 次行动，直接得知管道在别处漏水或被堵。 |
| `K20` | 应急旁路手轮。花 1 次行动，令**尚未发生**的第一段涨水事件各推迟 4 轮；手轮随后卡死，只能用一次。 |
| `F01—G01` | 通向洞穴。乘客进入洞穴 `F22—G28` 中任意一格，就算救出；玩家之后可以继续领他们走，也可以让他们留在安全区。 |

鹈鹕听见过“洞穴的管子会吹口哨”，询问便直接说。鹈鹕获救后把自己的 **迷你无人机**送给玩家，照道具表计入全局数量。三个乘客都不是玩家必须选择的角色，也没有受伤状态。

### 第一段的事故时间表

开局算第 1 轮。六名玩家各行动一次后，主持人结算轮末。下表只看轮数，不等玩家走到指定场景才开始。两处故障都修好后，**停止尚未发生的涨水事件**；已经出现的浅水和断桥不会瞬间消失。应急旁路开启时，将尚未发生的表项统一向后推 4 轮。

| 轮末 | 地图变化 |
| ---: | --- |
| 5 | 湿地 `C09—J23` 中原本可走的低地变成浅水，进入消耗 2 点；步道、小岛不变。 |
| 10 | 湿地步道 `G18` 冲断，不能通过。安全绳网可花 1 次行动架在 `F18—H18` 间恢复通路；`F17` 也有一块木板，花 1 次行动铺上达到相同效果。 |
| 15 | 洞穴中央 `F17—G17` 落下碎石，不能通过。玩家可从左右两侧绕行，或花 2 次行动搬开。 |
| 20 | 湿地 `A01—L09` 中原本可走的低地变成浅水，进入消耗 2 点。 |
| 24 | 若洞穴裂管与雨林滤网尚未**全部修复**，列车紧急停车。此后仍可救人、修理，但失去“继续行驶”结局。 |

如果结算时有人站在刚变成障碍的格子，把他放到刚才进入这一格的一侧，不造成伤害。深水池始终不能步行通过；新增浅水只覆盖原本可走的低地。断桥修好后仍保持通行。第一段可在修好两处故障、三名湿地乘客安全后自然收束，通常用 **60—90 分钟**。

## 第二段：水回来了，热还在

两处水循环故障都修好时，通向火山车厢的隔热门打开，主持人立即告诉玩家：**冷却水重新流进火山车厢，但之前断水留下的高温还没退。两名乘客困在里面。**第二段热量计从此开始结算，玩家仍在原位置，照常掷骰走过去。如果第一段已经紧急停车，火山车厢仍需要降温和救人，只是无法拿到完整胜利。

火山车厢仍是 **12×28**。进入 `F01—G01` 后，左右两边都有路，中央较短但有蒸汽。目标是**启动冷却循环并救出两名乘客**；先做哪件由玩家决定。

| 坐标 | 内容与效果 |
| --- | --- |
| `F10—G20` | 热地面，进入消耗 2 点移动。 |
| `F12—G12`、`F18—G18` | 蒸汽喷口。第二段的偶数轮末喷发；站在这些格上的玩家被推回 2 格，并失去下一轮的那次行动，移动仍可进行。玩家能从两侧绕行。 |
| `J22` | 冷却循环手柄。花 1 次行动打开；冷却水已恢复，所以不用掷骰。此后热量不再上升，蒸汽喷口在 **2 轮末后**停止。 |
| `B21` | 一名山羊乘客躲在观景台下。玩家到相邻格花 1 次行动让其跟随。 |
| `K17` | 一名乌鸦乘客守着关不上的保温帘。玩家到相邻格花 1 次行动让其跟随；不要求先修帘子。 |
| `F01—G01` | 通向湿地。两名乘客进入湿地 `F24—G28` 中任意一格便安全。 |

火山内不存在必须找到的隐藏密码。**冷却手柄在地图上标明位置**，所以玩家可选择先冲过去降温，再护送乘客；也可先接到乘客，走两边较长但安全的路撤出。山羊与乌鸦可以在玩家开口时直接说明自己看见的蒸汽喷发节奏。

### 第二段的热量计

水循环刚恢复时，热量为 **2**。第二段每过 3 轮，若冷却手柄仍未打开，热量 +1。到 **6** 时列车停车；蒸汽仍按表喷发，玩家可以继续救人。主持人把热量数字写在纸上，公开给玩家。冷却手柄打开后热量不再上涨，两轮后降到 0，蒸汽停止。

这段通常用 **45—60 分钟**。加上开场分路、第一段和结局，整局以 **2—3 小时**为目标。如果六人非常快地分工并直接找到所有设施，实际时长仍以他们的游玩速度为准，不靠主持人藏线索或强行加轮数。

## 主持人速查与结局

| 玩家做了什么 | 立即发生什么 |
| --- | --- |
| 洞穴 `J18` 装好管箍 | 裂管修复；洞穴因漏水增加的浅水不再扩大。 |
| 雨林 `C04` 取出堵布 | 雨林恢复降雨；若裂管未修好，下一轮洞穴 `H10—K24` 变浅水。 |
| 两处都修好 | 第一段水位时间表停止；火山隔热门打开，第二段热量计开始。 |
| 湿地乘客到洞穴安全区 | 每到 1 名记 1 名获救；鹈鹕到达时送无人机。 |
| 火山 `J22` 打开手柄 | 热量停止上涨，两轮后归零，蒸汽停止。 |
| 火山乘客到湿地安全区 | 每到 1 名记 1 名获救。 |

- **列车继续行驶**：第 24 轮紧急停车前修复两处水故障，火山热量未到 6，五名乘客全部获救，冷却手柄已打开。
- **安全停车**：任一时限触发停车，但玩家仍完成修理、降温与救援。列车留在原地等待检修。
- **尚未收尾**：仍有乘客或故障未处理时，结局保持开放；主持人直接说清还有哪一项没完成，玩家可以继续行动。

固定解法都按表直接成功；行动骰留给玩家提出的其他合理办法，例如跨深水、改造道具、从管外补漏或另搭桥。主持人只需裁定这些新办法，不用临场编造关键线索、事故答案或通关条件。
