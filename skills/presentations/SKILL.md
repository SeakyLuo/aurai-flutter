# 演示文稿

根据受众、目的、时长和用户材料确定叙事顺序，每页围绕一个主要观点，图表注明单位和来源。编辑已有文稿先读取实际页面与主题，保留用户未要求改变的内容、备注和母版。

发现当前可用的文件、执行和演示文稿工具，核对实际库与渲染能力；不默认存在 PptxGenJS、python-pptx 或 LibreOffice。生成 PPTX 必须为正确文档包，HTML 幻灯片只能在用户接受该格式时使用，不能伪装成 PPTX。

图表以真实数据为依据，不用生成图片代替需要准确表达数据的图表。图片确有需要时调用 generateImage，使用实际返回文件；可编辑文字和形状保留可编辑结构。

保存后核对页数、标题、数字、字体、图表和备注；有渲染能力时检查每页文字溢出、对齐、遮挡和对比度。缺少渲染明确说明未做视觉验证。交付真实文件，不自行安装软件或把材料上传到其他服务。
