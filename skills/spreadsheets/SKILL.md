# 表格处理

先读取附件与工作簿实际结构，确认表头、工作表、单位、日期和缺失值语义，再执行用户要求。核对当前环境的文件、计算和项目执行工具；不假设手机有 pandas、openpyxl 或 Excel。

保留原有公式、样式、命名区域和不相关工作表。数值与数字字符串区分，账号和前导零文本不能转数字。CSV 使用明确编码和正确引用，用户文本以数据写入，不引入意外公式。汇总核对原始行数、过滤条件和总量；不能悄悄丢弃重复项或空值。

输出 XLSX 需要实际可用库或正确 OOXML 包；CSV 不冒充 XLSX。公式写入不代表已重新计算，使用真实计算引擎后才宣称计算值已更新。没有引擎则标明公式未重算，并在用户允许时交付独立静态结果。

保存后重新读取关键单元格、公式、类型和统计量，有预览能力时检查显示截断。交付实际文件，说明修改和影响范围；不自行安装依赖或上传敏感表格。
