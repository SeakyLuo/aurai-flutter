# 可视化

仅当图形有助于理解时使用。根据任务选择比较图、趋势图、流程图或交互模拟；真实数据、示意值和假设明确区分。标注单位、坐标和来源，保持尺度正确，不用生成图片表达精确数据。

发现当前 HTML 消息/小程序工具并读取其 schema，用现有 HTML 容器呈现。单次可视化不必创建长期小程序或技能。遵循 App 容器的资源、脚本、尺寸与通信规则；不能使用 Codex 专属可视化指令或假定 CDN 和网络资源可用。

交互控件改变的量应清楚，默认状态可读，用户能返回初始参数；可见内容有文字解释，适配手机宽度、亮暗主题和触屏。不要把权限、内部 ID 或调试内容放入页面。HTML 中的异常走容器已有报错接口。

正式科学图、出版图或用户要导出的图形优先使用已有真实绘图工具输出文件。交付前检查文字、单位、极值和计算，有实际预览能力时验证操作和布局；没运行过的模拟不能宣称交互已验证。
