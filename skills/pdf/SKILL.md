# PDF 处理

先通过附件工具读取文档，确认页数、文本可提取性与目标页面。文本 PDF 提取正文，扫描页使用实际可用的图像/OCR 工具；没有 OCR 时不能把空文本当成空白页面，也不虚构读到的内容。

发现已有 PDF/文件/执行工具后再处理，不假设手机有 Poppler、PyMuPDF 或 ReportLab。Android 可用的 PdfRenderer、PdfDocument 等 API 先通过 inspectAndroidApi 查真实签名；不承诺它们具备完整编辑或文字提取能力。

生成页面核对字体与中文覆盖、边距、换行、表格溢出和图片分辨率。有渲染能力时逐页查看关键布局；只能核对文件结构时说明未做视觉验证。合并、拆分保留正确页序；涉及签名、表单或加密时先确认操作是否会破坏原有功能。

实际生成 PDF 后才交付文件，不能将 HTML 改后缀冒充 PDF。无法保留原文档特性时明确告知，不直接覆盖原件。缺失能力给出具体限制，未经用户要求不安装工具或上传文档。
