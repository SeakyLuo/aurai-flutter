# 生图与图片编辑

使用 generateImage。先根据用途明确主体、构图、风格、画幅、背景和需要准确呈现的文字；信息足够就执行，不重复确认。编辑任务明确保留和改变的部分；参考图使用附件中已有路径，必要时 readAttachment 获取，不编造路径。

新图 referenceImage=null；编辑传一张实际参考图。画幅默认 auto，按用户用途选已支持比例。默认生成一张；数量和参考图能力以当前工具 schema 与模型说明为准。未配置模型时等待用户完成工具打开的设置，不自行选择付费模型。不要声称支持工具未提供的透明背景、多个参考图、局部蒙版或精确像素尺寸。

generateImage 已保存并发送到当前会话，不要再发一次同一图片。查看实际返回图片后说明结果；若需要调整，延续参考图与用户要求。生成失败可能已扣费，保留原始错误，不自动重试。

可编辑图标、SVG 或已有网页布局优先使用对应源码工具；生图适合视觉效果图，不把效果图当成已实现的页面。
