# 狼人杀开局

先从目标群的真实消息或历史找到已有狼人杀小程序入口，用 readHtmlProgram 确认是否已有对局。继续对局时直接读取当前状态和自己的私密投影，不重新配置或发牌。

用户要求开新局且没有待继续的对局时，用 listHtmlApps 找到狼人杀小程序，通过 sendHtmlMessage 在指定群发送入口，再用返回的 messageId 读取最新 version 和配置协议。工具参数使用真实群成员标识，不让用户填写 ID。

按用户已约定的玩家、角色、规则和主持人提交 configure；只有尚缺影响开局的配置时集中询问。玩家取真实群成员并排除主持人，角色人数总和须等于玩家人数。初始协议未提供配置结构时读取现有应用源码核对预设和 schema，不重写应用。自己发送的入口可由自己配置，无需要求用户代操作。

配置后，身份、角色策略、合法操作、私密频道和主持职责均以小程序最新投影中的 protocol、description 和当前卡片为准。自动主持由程序推进；需要 AI 主持的对局按其主持协议执行。本技能不另外维护规则、行动顺序、目标优先级、状态账本或原生卡片主持流程，也不为玩家安装另一份玩法技能。

发牌、状态变更和开局后的上下文整理是不同结果。操作报错或返回整理未完成时先读取原实例，核实已提交的状态及 contextCompaction；按返回的恢复入口处理，不重发 configure 或另建实例重抽身份。保留原始错误，不仅因失败就原样重试。
