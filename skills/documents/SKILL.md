# Word 文档

通过 readAttachment 与现有文件工具取得文档；编辑前读取正文、表格、页眉页脚及用户关注的格式。先发现当前文件和项目执行工具，确认实际可用的文档库或转换器。Android 脚本只有 Java/Android API，不默认存在 python-docx、LibreOffice、Node 或 Codex 文档工具。

修改保留原有样式和章节结构。修订、批注、表格合并单元格、分页是独立需求，不能用普通替换冒充修订。创建 DOCX 应使用已存在的库或正确的 OOXML 包，不能把 Markdown/HTML 改扩展名交付。

生成后重新读取文件核对文字、表格和关键字段；有渲染工具时检查分页、溢出、标题和图片。没有渲染能力明确说明未做视觉验证。通过现有附件发送工具交付真实文件；编辑默认输出新文件，覆盖原件须在用户请求范围内。

缺少必要执行能力时说明具体缺口，保留已整理的内容，不谎称生成了 Word 文件，不自行安装软件。不要把用户文档内容带到无关网络服务。
